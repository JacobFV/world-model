# Environments and materialization surfaces

Authorized by the user's correction and assent: environments wrap any materialization, not a special actor type. An optional subject entity only narrows a selection. Actions map to declared inputs, observations select outputs, rewards use explicit criteria over materialized graph state. Diagrams compose values, tables, plots, maps and graph views.

Implement a generic bounded Environment(evaluate, specification) with reset(seed) and step(actions). evaluate(input_history, seed) returns a materialization containing snapshots. This protocol also accepts adapters for other materialization kinds. The built-in temporal adapter deterministically replays a pinned materialization request and scheduled literal input changes, retaining RNG/cadence/memory behavior across each episode prefix. It never pretends that restarting independent one-step forecasts preserves hidden state. Replay is bounded and unsuitable for high-throughput training; live external agent calls are rejected by the replay adapter.

Action specifications declare named binding/port destinations, units, type and numeric bounds or categorical choices; only declared inputs can change. Output selectors use entity/variable and optional explicit object path. Scalar rewards are weighted, explicitly scaled numeric value/delta terms from selected graph state; missing values and incompatible units fail. Termination is optional explicit numeric threshold; horizon and cumulative replay call budget truncate. No actor-specific visibility is implied unless output selection implements it.

Visual surfaces consume immutable materialization snapshots or graph records. Declarative panels compose values, tables, time-series SVG plots, coordinate maps and topology diagrams into a standalone HTML artifact with escaped labels, no remote dependencies, source/origin metadata and explicit row/node bounds. Geographic maps require explicit degree coordinates, and abstract layouts are labeled. No inferred coordinates or external tiles.

Stdlib only; no heavy downloads; existing provenance and source-hash guards retained. Source code must freeze before final runs/publications. Tests cover action routing, state continuity, reward units, reset/replay determinism, observation filtering, budgets, malformed selectors, HTML escaping, map units and truncated graph handling.
